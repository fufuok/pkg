`pubsub` 提供简单的多主题发布订阅功能, 内嵌自 [cskr/pubsub](https://github.com/cskr/pubsub). 上方文档链接指向上游; 本仓库使用 `github.com/fufuok/pkg/pubsub` 包路径.

安装本仓库版本:

```shell
go get github.com/fufuok/pkg
```

```go
import "github.com/fufuok/pkg/pubsub"
```
